# Instructions for AI agents

Read `START_HERE.md` first, then `COLLABORATION.md`, then `decisions/DECISIONS.md` and the latest three files in `sessions/`.

Before changing anything: `git pull --rebase`, and work on your own branch or worktree (see `COLLABORATION.md`). When you finish, add a session note in `sessions/`, commit, push to GitHub, and make sure the owner's Obsidian vault copy is updated (see `COLLABORATION.md`, "How GitHub and the Obsidian vault are linked").

The owner is a capable marketer who is still building coding experience. Be concise and direct; briefly explain any git, cloud or code step that is not obvious, without over-explaining. Never leave work only in a chat: commit it and write a session note.

## Standards for anything that goes out (owner, 2026-10-29)
- **Natural phrasing**: copy should read like a person wrote it, not a model. No clipped fragment strings or stock AI tics.
- **Double size for all visual assets** (LinkedIn 4:5 = 2160x2700 PNG).
- **Breathing room and best design practice**: generous spacing, balanced line breaks, clear hierarchy; always look at the render before sharing. Details: `brand/visuals/README.md`.
