# Playbooks: weekly rhythm and universal SOP

All timings and tactics here are **hypotheses to test**, not facts. The log records results so we can change them.

## Post types

| Type | File | Share of the week |
|---|---|---|
| Data post | `data-post.md` | 1-2 |
| Policy / market take | `policy-take.md` | 1 |
| Story / people / behind the scenes | `story-bts.md` | 1 |
| Product / launch | `product-launch.md` | 0-1 |
| Partner / customer proof | `partner-customer.md` | 0-1 |

## Weekly rhythm (starting hypothesis)

| Slot | 4-post week | 5-post week extra |
|---|---|---|
| Tue | Data post (flagship) | |
| Wed | Policy / market take (floats to the day the news breaks) | |
| Thu | Story / people | |
| Mon or Fri | Product, partner proof or a second data post | A light community or cause post |

**Weekly cycle:** the ideas board digest arrives Wednesday morning; the founder content review is on Wednesday; posts picked there are drafted, approved and scheduled into the next week's slots.

Aim to publish in UK working-hour mornings. Move slots to match news. Review reach by slot after 6 weeks.

## Universal SOP (every post)

| When | Step | Who |
|---|---|---|
| Before go-live | Keep a buffer of 8-10 approved or ready drafts | System + owner |
| T-48h | Draft produced, visual rendered, claims list checked against the query that produced the numbers | System, owner |
| T-24h | Draft sent to Floris in Slack (Approve / Edit / Reject). SLA 24h. | Floris |
| T-0 | If not approved, swap in the next buffered post and re-queue the missed one | System |
| T-0 | Floris posts. Hypothesis: put any link in the first comment, not the body. | Floris |
| T-0 | Floris pastes the live link in the Slack thread; the system logs the live text and diffs it against the approved version | Floris, system |
| T+0 to T+60 min | Team tasks fire (see each playbook). Floris replies to every early comment. | Team, Floris |
| T+24h | Log reactions, comments, reposts, impressions if available | System / owner |
| T+7d | Log again, tag outcome (hit, ok, miss) with one-line reason | Owner |
| Weekly (Wednesday) | Founder content review: what worked, pick next week's posts from the ideas board, tune scores and slots | Owner + Floris |

## Pre-publish checklist

- [ ] Every number traces to a stored query and period
- [ ] Sample size at or above the agreed minimum cohort
- [ ] No customer, partner or person named without written OK
- [ ] No financial or legal advice; no promised outcomes
- [ ] Reads like Floris (`voice/floris.md`); hook is in the first two lines
- [ ] Visual matches the brand kit; alt text written
- [ ] Floris approved the exact final text
