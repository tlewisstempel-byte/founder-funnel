**How the profiles were found:** public LinkedIn profiles via web search (no scraping). Each URL is the *likely* match from name + employer shown on LinkedIn. **Confirm before following.** Roles marked "(LinkedIn: …)" show only the employer from the profile headline; the job title still needs checking.

**Tiers:** A = follow with the bell on and comment regularly (start here, ~30). B = follow; comment when Floris has something real to add. C = monitor only (competitor, politicians).

**Role slots:** buyer seats where the current holder couldn't be confirmed publicly. Fill from each company page > People, searching "home ownership", "sales" or "shared ownership".
